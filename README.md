# 📖 Project Overview

This project presents an interactive **Power BI dashboard** designed to analyze Starbucks beverage data through a business intelligence lens.

The dashboard enables users to explore nutritional information, beverage categories, caffeine content, calorie distribution, and Starbucks' global footprint using dynamic visualizations and interactive filters.

Rather than simply displaying data, the dashboard helps answer business questions that support product analysis and customer insights.

---

# 🎯 Business Objectives

✔ Understand beverage nutritional profiles

✔ Compare beverage categories

✔ Identify high-caffeine beverages

✔ Explore calorie and sugar trends

✔ Visualize Starbucks' global presence

✔ Deliver an interactive business intelligence report

# 📂 Dashboard Features

### 📌 Executive KPI Cards

Monitor key business metrics including:

- Total Beverage Types
- Average Calories
- Average Sugar
- Average Caffeine

---

### 🌍 Global Starbucks Presence

Analyze Starbucks store distribution across multiple countries.

**Business Value**

- Market comparison
- Regional analysis
- Expansion insights

---

### 🍹 Beverage Category Distribution

Interactive donut chart displaying the percentage distribution of beverage categories.

Examples include:

- Classic Espresso Drinks
- Frappuccino
- Smoothies
- Tea
- Signature Drinks

---

### 📈 Nutrition Analysis

Explore:

- Average Calories by Category
- Average Caffeine by Category
- Sugar Analysis

Identify healthier beverage options and compare nutritional profiles.

---

### 🏆 Top 5 Highest Caffeine Beverages

Quickly identify beverages with the highest caffeine content for comparison and analysis.

---

### 🎛 Interactive Filters

Users can dynamically filter the dashboard by:

- Protein Range
- Beverage Preparation Type

making the dashboard fully interactive.
